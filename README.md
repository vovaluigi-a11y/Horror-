# HORROR STUDIO

Личная производственная студия коротких хоррор-видео (analog horror, found footage, VHS, лиминальный хоррор, псевдодокументалистика). Работает целиком в браузере: без сервера, без установки программ, без платных API.

**Сценарий работы:** идея → оценка → раскадровка → промпты → изображения → документальный монтаж → звук → контроль качества → MP4 1080×1920, 30 FPS.

## Как запустить

Это статический сайт: `index.html`, папки `css/` и `js/`. Сборка не нужна.

* **Любой HTTPS-хостинг** (GitHub Pages, Netlify, Cloudflare Pages и т. п.): загрузите файлы как есть. HTTPS обязателен: без него браузер отключает кодировщик видео.
* **Локально:** `python3 -m http.server 8000` в папке проекта, затем откройте `http://localhost:8000`.
* **GitHub Pages для этого репозитория:** Settings → Pages → Deploy from a branch → выберите ветку и папку `/ (root)`.

Лучше всего работает в Chrome или Edge на компьютере с видеокартой.

## Что реально работает

| Функция | Как сделано | Статус |
|---|---|---|
| Монтажный движок | WebGL2-шейдер: камера, параллакс 2.5D по карте глубины, ручная съёмка, фокус, экспозиция, VHS/цифровые повреждения, зерно, OSD | ✅ |
| Выбор движений и переходов | Анализ пикселей (точки интереса, линии, яркость) + драматургия кадра; запрет повторов подряд | ✅ |
| Защита от чёрных краёв | Математическая проверка покрытия кадра при каждом движении + проверка по отрендеренным кадрам | ✅ |
| Звук | Собственный синтез: гул, шипение, радио, щелчки, сбои, акценты, тишина; 6 дорожек с громкостью | ✅ |
| Синхронизация звука и сбоев | Каждое визуальное событие порождает звуковое в том же кадре; проверяется по сигналу | ✅ |
| Экспорт MP4 | WebCodecs H.264 + mp4-muxer → настоящий файл MP4 | ✅ |
| Звук в MP4 | AAC там, где браузер его кодирует (Chrome/Edge на Windows/macOS/Android, Safari). Chrome на Linux не кодирует AAC → Opus внутри MP4 | ✅ / ⚠️ |
| Проверка готового файла | Браузер заново открывает MP4: декодирование, длительность, кадры сцен, звуковая дорожка | ✅ |
| Генератор идей | Алгоритмический: библиотека элементов + оценка + история + учёт «нравится» | ✅ (это не нейросеть) |
| Идеи и раскадровка от языковой модели | «Мост с ChatGPT»: готовый запрос → ответ вставляется обратно и разбирается автоматически. На страницах claude.ai дополнительно доступна встроенная ИИ-генерация | ✅ |
| Генерация изображений | **Внутри сайта недоступна без платного API.** Сайт готовит промпты (по отдельности или одним сообщением), изображения вы получаете в ChatGPT и перетаскиваете — они сами распределяются по кадрам | ⚠️ альтернатива |
| Контроль качества | План монтажа + рендер ~400 кадров с анализом + анализ звукового сигнала; автоисправления | ✅ |
| Хранение | IndexedDB в браузере + резервная копия проекта в файл | ✅ |
| Шаблоны стилей | 5 встроенных + свои | ✅ |

## Честные ограничения

1. **ChatGPT Sites.** У меня нет доступа к этому продукту, поэтому я не мог проверить, можно ли разместить там этот сайт. Приложение — обычный статический сайт без сборки, поэтому, если ChatGPT Sites принимает собственные HTML/JS-файлы, оно должно работать и там. Если нет — используйте любой бесплатный HTTPS-хостинг.
2. **Изображения.** Опубликованный сайт не может вызвать генератор изображений ChatGPT без API. Кнопки «сгенерировать фото» нет намеренно.
3. **Движение людей.** Из одной фотографии человек не начнёт ходить. Движок оживляет кадр работой камеры, параллаксом и повреждениями записи, но не анимирует персонажей.
4. **AAC.** Зависит от браузера (см. таблицу). Итоговый файл всегда MP4/H.264.
5. **Данные хранятся в этом браузере.** Делайте резервные копии проектов (Архив → «Скачать проект»).
6. **Контроль качества — технический.** Он измеряет движение, края, экспозицию, звук и синхронизацию, но не оценивает, страшно ли получилось.

```
js/engine/audio.js    синтез и сведение звука
js/engine/export.js   экспорт MP4 и проверка файла

tools/engine-test.html   автотест движка
```
